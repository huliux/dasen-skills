# Workflow vocabulary

Contributor reference for terms used in the installation and content contracts.

| Term | Meaning |
|---|---|
| Project enablement | Makes the suite discoverable to a selected Agent in one content project. User-directory storage alone is not global enablement. |
| Shared runtime | A verified environment reused by matching releases. Projects keep independent version choices and content. |
| Local readiness | Artifact integrity, dependencies, and deterministic local operations pass. Native Agent discovery is a separate check. |
| Environment readiness | Local readiness plus verified native discovery of the selected release. |
| First creation success | The requested article and deliverables meet the contract, editorial, and completion judgments. |

For behavior and acceptance, read the [specification](docs/spec.md).
