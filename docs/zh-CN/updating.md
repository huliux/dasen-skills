# 升级与卸载

[English](../en/updating.md)

把目标版本的完整安装包交给 Agent，再说明：

> 请按包内 INSTALL.md 升级当前项目的 dasen-skills。先核对当前版本和已有修改，保留旧版本及文章，再准备新环境并切换，最后检查实际加载的版本。

同一个项目已登记的工具一起切换；其他项目保持原版本。有冲突时保留用户修改并说明处理方式。

需要回滚时，让 Agent 按 INSTALL.md 使用此前版本的回执重新绑定。版本回滚不等于恢复文章或配置备份。

需要卸载时，说“请移除当前项目的 dasen-skills 自管入口，保留文章和共享环境”。共享文件与运行环境不会自动删除。

移动项目或换电脑后，需要重新接入并验证；直接复制虚拟环境不能替代这一步。详细操作见 [INSTALL.md](../../INSTALL.md)。
