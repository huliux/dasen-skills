# 兼容性

[English](../en/compatibility.md)

当前用于 Alpha 准备与社区测试，尚未承诺完整生产支持。

| 环境 | 当前状态 |
|---|---|
| macOS + Codex CLI | 项目发现、本地脚本与 HTML 导出已有验证；完整创作仍需测试 |
| macOS + Claude Code | 项目接入与本地执行已有验证；完整创作曾超时，仍需测试 |
| macOS + Codex 桌面版 | 安装绑定已实现；桌面内使用待验证 |
| Windows | 暂无自动安装与项目绑定入口；手动路线供开发者测试 |
| 其他 Agent | 待社区验证 |

已装有同名全局 Skill 时，应检查实际加载路径；Claude Code 可能优先加载个人入口。内容的事实准确性与交付完整性仍需人工复核。

普通写作和本地 HTML 不需要额外账号。联网检索、生图、云存储和微信远程草稿按需配置、分别测试。

遇到问题，欢迎在项目仓库提 Issue 或 PR，附上系统、工具版本、复现步骤及脱敏结果。贡献者可在源码的 `docs/evidence/` 查看详细验证记录。
