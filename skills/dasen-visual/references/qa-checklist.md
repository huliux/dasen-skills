# Asset checks

Use the final evidence/visual-plan.yaml after stable prose; provisional planning is not a final Asset Check.

## Every asset

Verify job/acquisition matches a concrete paragraph and serves one relationship. Remove private information, secrets, real backend/customer data, and local-machine paths. Style references remain inputs rather than automatically published pixels. Include configured identity only when authorized; no borrowed creator characters/mascots/signature composition.

## Existing pixels

Check credential-free source locator, acquisition time, project-relative untouched copy, SHA-256, and dimensions. Honor user assets or disclose factual conflicts. Treatment is preserve/crop/annotate/translate; derivatives never overwrite originals. Pending/accepted/rejected reflects actual human choice, not agent selection. Capture scope is public/current-task/authorized and redacted. Treatment preserves original facts/numbers/arrows/order. Human draft review owns phone appearance; it is not an automatic discovery rejection gate.

## Created assets

Verify frozen body/cover Style ID/revision and separate layout/role/Adapter/provider. Direction contains only focus/density/include/omit with an existing semantic focus and no protected overrides. Schema v3 explicitly records semantic slots, Direction, and Render Target. Check actual body preview at display_width_px and source-font scaling; cover key content stays inside compiled pixel safe areas. Style token references resolve, the method is compatible, and Chinese labels/arrows/order are correct.

## Required cover

Optional topic_label appears verbatim in title/final cover only when enabled; placement follows the chosen layout. Style/Adapter/provider/model match the resolved brief. Record layout, filled prompts, cover.yaml, source/final hashes, and applicable storage receipt. Binaries stay at frozen assets.root; package evidence contains audit text. Final dimensions match the project; Chinese/English are correct and title/label readable as phone thumbnails. Respect layout structure without presenting a generated cover as a real screenshot/result. Image models guide visual generation; critical title/numbers/long text receive post-generation layout and verification.

## Article and handoff

Select each asset for its information task without a universal official/capture/create hierarchy. No abstract placeholders or evenly spaced quota; distinguish mandatory/optional assets and verify files open at usable dimensions. Append actual results to record.md > Asset Check. Unresolved failures prevent ready.
