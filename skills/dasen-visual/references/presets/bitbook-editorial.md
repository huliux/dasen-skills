# Legacy bitbook-editorial layout recipe

Load only for legacy visual.preset migration or explicit compatible layout use. This original recipe is not a Style ID or permission to insert identity. It maps to body-whiteboard-clarity and cover-clean-editorial; its concrete colors/coordinates remain layout-local.

Body examples use landscape 16:9, white/warm-light-gray, hand-drawn black lines, orange main actions, blue feedback/state, and red risk. Use whitespace, one main structure, and 3–5 short Chinese labels. Slight irregularity/paper texture is allowed; fixed characters/mascots are not.

Use real screenshots for functionality/results, structure diagrams for process/branching, simple sourced plots for exact numbers, and usually no image for pure emotion/decoration. Avoid borrowed creator identity/composition, abstract stock-tech imagery, whole-article overload, unauthorized brand/product/persona, and unsupported numbers/logos/screenshots.

The adjacent prompt-template.md supplies a conditional example. Explicit topic-cover rendering uses scripts/render_topic_cover.py --preset dasen-editorial. Preserve bitbook-editorial as a legacy configuration input, not a second Skill entry.
