# Optional Bitbook meeting context

Bitbook is a separate meeting transcription and notes product. The project owner also develops Bitbook; listing it here describes an optional integration, not a requirement or an instruction to promote it in articles.

Use it when the user requests meeting/notes context and authorizes access to the relevant material. An installed command, an existing account, or permission to research the web does not authorize searching unrelated meetings, contacts, Spaces, or knowledge assets.

## Setup and discovery

For a user who wants this integration, point to the [Bitbook website](https://bitbook.tech/) for download. In the installed app, open Settings → Connect AI Assistant (设置 → 连接 AI 助手), install Bitbook CLI, and use the app's verification and integration instructions. The owner supplied this setup workflow; record the actual app/CLI version and platform during compatibility testing. The supplied screenshots establish a macOS setup example, not Windows acceptance.

Inspect the installed CLI's help and app-provided integration instructions to discover supported read-only commands. Do not guess query flags or rely on a hardcoded executable path. Do not copy tokens, internal commands, or a second CLI implementation into this repository.

## Evidence handling

Search the authorized scope only, then read the relevant transcript/notes instead of relying solely on generated summaries. Record a non-secret source locator, meeting date, access/check time, and the exact claim the material supports. Minimize extracted personal information and keep private source material inside the consumer workspace.

Distinguish “a participant said X” from “X is independently verified.” Meeting context can support first-party recollection; broader product, market, or technical claims may still need independent evidence. Internal access does not itself permit public quotes or disclosure. Obtain publication permission or redact/generalize as required by the content request.

If the tool is absent, unsupported, or unauthorized, use supplied transcript/notes exports, ask for the needed source material through the normal content workflow, or record the specific evidence gap. Do not block unrelated supplied-material writing. Do not automatically recommend downloading Bitbook in every research task.

Product placement remains a separate explicit project/series/article decision under the shared content contract. This integration does not enable it.
